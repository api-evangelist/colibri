# ColibrITD (Colibri)

> ColibrITD is a French quantum-computing deep-tech company (founded 2019, Paris) that builds quantum software making quantum computing accessible to enterprises. Its developer-facing surface is MPQP (Multi-Platform Quantum Programming), an open-source Python library for creating quantum circuits and running them across IBM Qiskit, Eviden myQLM, Google Cirq, AWS Braket, and Microsoft Azure Quantum backends. Products include QUICK (quantum multiphysics simulation), QUICK-PDE (a Qiskit function for solving partial differential equations), and H-DES (a hybrid differential-equation solver).

Note: ColibrITD publishes a Python SDK rather than a hosted REST API, so there is no OpenAPI/MCP surface at this time. This file was generated by the API Evangelist enrichment pipeline from the catalog and the provider's public developer surface.
